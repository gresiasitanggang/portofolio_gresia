# Gresia Sitanggang Portfolio
A modern, responsive personal portfolio website built with React, TypeScript, and Tailwind CSS, featuring interactive project showcase, experience timeline, and photo gallery.

# Features
- Responsive design across desktop and mobile devices.
- Interactive Project Showcase with category filtering (Software Engineering, Machine Learning, Digital Media) and detailed carousel modals.
- Comprehensive Sections: Home, About Me, Education, Experience, Projects, Certifications, Skills, and Gallery.
- Automated Deployment via GitHub Actions to GitHub Pages.

# Tech Stack
- Framework: React 19 + TypeScript
- Build Tool: Vite
- Styling: Tailwind CSS v4
